# Release Notes

**No formal version-tagged release history (semver tags, GitHub Releases, a CHANGELOG file) exists in this repository.** What exists instead is an extraordinarily detailed, dated engineering log in root `CLAUDE.md`, documenting each major feature as it was built, along with real bugs found and fixed along the way. This section synthesizes that log into a release-notes format, per this documentation set's required structure.

- [v1.0.0.md](v1.0.0.md) — synthesized "current production state" release notes
- [future-releases.md](future-releases.md) — pointer to [17-roadmap](../17-roadmap/README.md), since no future release is formally scoped

## A note on dates

Every dated entry below is taken directly from root `CLAUDE.md`'s own section headers, which do carry real dates (e.g. "2026-08-10," "2026-07-14/15"). These are the most reliable date signal available in the repository — `git log` was not re-walked commit-by-commit for this documentation pass, so treat the dates below as feature-level milestones, not exact commit timestamps.
